Zotero Tools

Five Zotero plugins and Book Helper. Install each separately.

The plugins target Zotero 9.x and 10.0.x on macOS. See each repository for setup requirements and testing details.

Install a Zotero plugin

An .xpi file contains a Zotero plugin. The plugin runs inside Zotero rather than as a separate Mac app. Do not unzip the file.

  1. Use a Download plugin (.xpi) link below and save the file to your Mac.
  2. Open Zotero. In the menu bar, choose Tools → Plugins.
  3. Click the gear button at the top of the Plugins window, choose Install Add-on From File…, and select the downloaded .xpi file. You can also drag the file into the Plugins window.
  4. Confirm the installation if prompted, then restart Zotero.
  5. Complete the setup listed under that plugin below.

Zotero’s plugin installation guide

Praetor

Use Codex or Claude Code in Zotero to ask about items, search attachment text, draft notes, and review proposed library changes.

Before use, install and sign in to Codex CLI or Claude Code, a separate command-line program. Open Zotero’s AI pane, choose that program, and select Check Login. The setup instructions list the required program locations. Zotero’s local connection is enabled by default; the setup instructions explain how to restore it if it has been disabled.

NotebookLM Pane

Open Google NotebookLM in Zotero’s item pane and prepare local PDFs for its upload dialog.

After installation, open the NotebookLM pane and sign in to your Google account there. To add a PDF, right-click an item and choose Send PDF to NotebookLM, then complete the upload in NotebookLM’s file dialog. Internet access is required.

Page View

Add single-page reading, two-page spreads, page fitting, and focus mode to Zotero’s PDF reader.

No additional software or account is needed. Use the PDF reader’s view buttons or Tools → Page View.

Compact Pane

Show a reduced set of metadata fields by item type, expand the full list when needed, and copy attachment paths from the item menu.

No additional software or account is needed. Select an item and use the compact/expanded field control in its information pane.

Quiet Theme

Apply a compact interface stylesheet and switch Zotero’s native light or dark appearance.

Open View → Quiet Theme to choose an appearance or enable the compact overlay. Restart Zotero after enabling or disabling the overlay.

Book Helper

Identify and rename PDF and DRM-free EPUB books, review their metadata, and optionally import them into Zotero.

A separate Mac application for macOS 13 or later on Apple silicon. Download the .dmg disk image, open it, and drag Book Helper to Applications. Open the app from Applications. Keep Zotero open if you want to import books into it.
