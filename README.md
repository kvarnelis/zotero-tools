# Zotero Tools

A single home for independent Zotero plugins and the Book Helper companion Mac app, with descriptions, setup links, and direct downloads. Each plugin is installed and updated separately.

This is a static GitHub Pages site. It uses plain HTML and CSS, system fonts, and no JavaScript, external assets, analytics, or build dependencies.

## Preview

Run `python3 -m http.server 8000` in this directory and open `http://localhost:8000`.

## Publish

GitHub Pages serves the root of the `main` branch. The public page is https://kvarnelis.github.io/zotero-tools/.

## Maintain

Edit `index.html` and `style.css`. Plugin links point to each repository and its latest release, so ordinary plugin updates do not require changes here. The Book Helper DMG is versioned; update that link when a new app release appears. Keep supported-version statements aligned with the linked READMEs. Never add library exports, private examples, local configuration, or screenshots of real libraries.
