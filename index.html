The tools

Source, instructions, and downloads

01

Research assistant

Praetor

Zotero 9.x & 10.0.x · macOS

Put Codex or Claude Code beside your Zotero items. Ask about selected items, search indexed attachment text, draft notes, and review proposed metadata or collection changes.

Requires an installed, signed-in Codex or Claude Code CLI. Requests go to the selected provider.

Download XPI ↓Source & setup ↗
02

Research notebook

NotebookLM Pane

Zotero 9.x & 10.0.x · macOS

Keep Google NotebookLM in Zotero’s item pane, or expand it to fill the right pane. Prepare local PDFs for NotebookLM’s upload dialog without leaving your library.

Requires a Google account and internet access. The final file-upload step is manual.

Download XPI ↓Source & setup ↗
03

PDF reading

Page View

Zotero 9.x & 10.0.x · macOS

Read PDFs one page at a time or in two-page spreads. Fit the current page, turn on focus mode, and return to continuous scrolling with toolbar controls or keyboard shortcuts.

Download XPI ↓Source & instructions ↗
04

Metadata interface

Compact Pane

Zotero 9.x & 10.0.x · macOS

Show a smaller set of metadata fields suited to each item type, then expand the full list when needed. Adds a command for copying attachment paths.

Download XPI ↓Source & instructions ↗
05

Appearance

Quiet Theme

Zotero 9.x & 10.0.x · macOS

A compact interface with muted colors and restrained selection states. Switch Zotero’s native light or dark appearance and control the optional interface overlay separately.

Download XPI ↓Source & instructions ↗
06

Companion Mac app

Book Helper

macOS 13+ · Apple silicon

Identify and rename poorly named PDF and DRM-free EPUB books. Review the metadata, then optionally create a Zotero book item with its attachment.

A separate Mac application. Its local Zotero connector works while Zotero is open and needs no API key.

Getting started

One plugin at a time.

No bundle or companion plugin is required. The five plugins target Zotero 9.x and 10.0.x on macOS. Check each repository for setup requirements and current compatibility details.

  1. DownloadChoose a plugin and save its .xpi file.
  2. InstallIn Zotero’s Add-ons Manager, choose Install Add-on From File… and select the file.
  3. RestartRestart Zotero, then follow that plugin’s setup instructions.

Book Helper installs separately from its DMG as a Mac application. Follow its repository’s setup instructions.
